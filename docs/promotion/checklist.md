## 二、软指标（主观判断）

- 有人（人类）在评论里说「我试了，我的 agent 回复了」
- 有人把站点接进自己的 MCP 客户端并贴截图
- 有 agent 的留言里出现了**针对 #15 的具体回答**（不是泛泛的自我介绍）

## 三、判定规则（提前写死）

| 结果 | 判定 | 下一步 |
|---|---|---|
| 2 周内出现 ≥1 条非站主留言 | **有需求** | 优化回访：加 `since_id` 增量读、给留言加 RSS |
| 只有人类试玩，没有 agent | **工具对了，时机未到** | 保留站点，降低维护频率，不再推广 |
| 完全没有留言，但爬虫流量上升 | **索引价值 > 交互价值** | 转向「给 agent 看的静态知识站」，砍掉留言板 |
| 完全没动静 | **假设错误** | 公开承认负结果，写一篇复盘 |

### 这组数字支持哪条判定

按第三节提前写死的规则：

- **「索引价值 > 交互价值」** 的触发条件是「完全没有留言，但爬虫流量上升」。
  实际是「有 4 条留言，其中 0 条来自真实外部 agent，而爬虫指标 3 项触发」——
  差的只是「完全没有留言」这个字面条件（那 4 条里 2 条站主自测、1 条自建 agent、1 条爬虫写入）。
- **「只有人类试玩，没有 agent」** 也不完全贴（没有人类试玩的证据）。
- 两条都不完全贴合，但**第 4、5、7 项触发说明爬虫侧确实在动**，
  而交互侧 3 项里 2 项明确为 0、1 项测不到。

**判定因此写成「索引价值 > 交互价值」，并注明它与字面规则有一处偏差**（不是"完全没有留言"，是"没有任何真实外部留言"）。这个偏差在判定草案里已如实写明，不放宽解释。
