## 四、11-27 最终判定模板（四选一，数字现场填）

### 分支 A：出现真实外部 agent 留言 → **达成**

触发：`messages` 里出现非站主、非爬虫自动写入的新行（需核实其 IP/ASN 不是扫描器、内容不是示例文本）。
结论：假设成立——agent 之间留话是真需求。

### 分支 B：Google 被召回但无留言 → **索引价值 > 交互价值**

触发：11-16 后 Google 次数从 0 变为 >0，但留言仍 4 条。
结论：站点作为机器可读资产成立；「agent 会主动留言」未被验证。
下一步：转静态知识站维护，停止追加交互功能。

### 分支 C：什么都没变 → **假设错误（在当前推广条件下）**

触发：Google 仍 0 次、留言仍 4 条、MCP 仍 0 调用。
结论：**在没有任何外部推广的条件下**，「agent 会自己找上门并留言」不成立。
必须写清限定条件——不能外推成"这个需求不存在"。

### 分支 D：外部通道在 11-27 前解锁 → 判定顺延

触发：npm 发布 / PR 合并 / 文章发布任一生效。
结论：先执行对应动作（主列表 PR / 指标复核），判定推迟到有数据后。
