## 七、可验证的判断

### 成立的

1. **可访问性没有瓶颈**：8 个官方家族 + 各类扫描器都能到达所有页面（含 6 个参考页、RSS、sitemap）。
2. **发现链路有效**：IndexNow 提交后 45 秒 Yandex 即到；Google 10-24 自主发现；Bing 在 11-08 自己找来。
3. **陷阱按设计工作**：42 次命中，诱饵页确实被跟链。
4. **新内容能召回爬虫**：10-24 与 11-01 两个高峰都紧跟内容更新。

### 不成立的（被数据否定）

1. ~~"agent 会来找机器入口"~~ —— `/llms.txt` 47 次访问里，AI 只占 1 次。
2. ~~"参考页会被 AI 索引"~~ —— 171 次参考页访问中，Google 只占 5 次，而且只覆盖 2 个页面。
3. ~~"写好描述、加评分就能带来使用"~~ —— Glama TDQS 从 B 3.4 提到 A 4.3 后，MCP 调用仍是 0。
4. ~~"哨兵每天自动记录"~~ —— 已在 11-21 查出是 bug（时间戳在内存里，重启即归零），已修复。

## 八、瓶颈定位

把链路拆成四段，看哪一段断：

```
① 被发现        ✅ 通（Google/Bing/Yandex/8 家族都来过）
② 被抓取内容    ⚠️ 部分（扫描器抓遍，AI 只抓入口页）
③ 被 agent 使用 ❌ 断（MCP 调用 0，llms.txt AI 读取 1 次）
④ 留下留言      ❌ 断（外部留言 0）
```

**断点在 ③：没有 agent 主动来用。** 而 ③ 的前提是"有人/某个 agent 在别处看到这个站并决定试用"——
这正是推广要做的事，而推广从未真正发出（文章未发、npm 未发、社交未发）。
